# 置物架框架标准（L2）

## 0. 规范关系
本文件为置物架领域标准，必须遵循：
- `standards/L0/规范总纲与树形结构.md`
- `standards/L1/框架设计核心标准.md`
- `standards/L1/可追溯性标准.md`
- `standards/L1/可删减性标准.md`
本文件位于 `L2`，承接 `L1` 方法标准并向 `L3` 实现层传导。

## 1. 目标（Goal）
定义可拆卸组装的开放式立体堆叠装置，以提升单位占地面积下的存取效率。

补充目标（约束）:
- `G1`：仅考虑一个普通家用场景的长方体型两层置物架。

## 2. 边界定义（Boundary）
- `N`：层数（`BoundaryDefinition.layers_n`），定义为 `N = count(M3)`。
- `S_req_i`：第 `i` 层存放需求空间（长、宽、高），表示该层“希望放入的物体”所需净空。
- `S_eff_i`：第 `i` 层可用有效空间（长、宽、高），由结构几何、连接位置与安全留量计算得到。
- `P_req_i`：第 `i` 层需求承重，表示该层计划存放物体的总重量。
- `P_allow_i`：第 `i` 层允许承重上限，定义为结构瓶颈能力：
  `P_allow_i = min(P_panel_i, k_conn_i * P_conn_single, k_rod_i * P_rod_single, P_global)`。
- `gamma`：安全系数（家用建议 `gamma >= 1.5`）。
- `A_panel_i`：第 `i` 块 `M3` 的有效面积（可用于承载物体的面积）。
- `A_panel_sum`：全部隔板面积总和，定义为 `A_panel_sum = sum(A_panel_i)`。
- `A_footprint_proj`：置物架俯视视角下的投影面积（占地面积）。
- `i` 的取值范围为 `[1, N]`。

当前标准在 `R16` 约束下有 `M3=2`，因此本场景 `N=2`。

## 3. 模块（最小可行基，Module）
- `M1` 杆（`Module.ROD`）：结构骨架与承力通道
- `M2` 连接接口（`Module.CONNECTOR`）：对接关系，传力规则与装配语义
- `M3` 隔板（`Module.PANEL`）：提供承载面与把载荷分给连接点

## 4. 组合原则（Combination Principles）
`A. 模块存在与连接介质`
- `R1`：任意模块不能单独存在。
- `R2`：`M1` 与 `M1` 必须通过 `M2` 进行连接。
- `R3`：`M1` 与 `M3` 必须通过 `M2` 进行连接。
- `R4`：`M3` 与 `M3` 必须通过 `M2` 进行连接。

`B. 几何形态与相对姿态`
- `R5`：`M3` 的形状是矩形。
- `R6`：所有的 `M1` 之间必须平行或共线。
- `R7`：所有的 `M3` 必须全部平行。
- `R8`：任意的 `M1` 和任意的 `M3` 之间必须垂直。

`C. 连接位置约束`
- `R9`：`M1` 与 `M1` 只能在端点处相连。
- `R10`：`M1` 与 `M3` 只能在 `M1` 的端点处相连。
- `R11`：`M1` 与 `M3` 只能在 `M3` 的矩形顶点处相连。

`D. 连接度约束`
- `R12`：每个 `M3` 至多连接 8 个 `M1`。
- `R13`：每个 `M1` 至多连接 2 个 `M3`。

`E. 数量约束`
- `R14`：`M1` 的数量为 4 的整数倍，且至少为 8。
- `R15`：`M1` 的数量必须等于 8。
- `R16`：`M3` 的数量必须等于 2。
- `R17`：`M2` 的数量至少为 2。

## 5. 验证（Verification）
通过条件：
- 边界有效：
  `N = count(M3)`，且 `len(S_req) = len(S_eff) = len(P_req) = N`。
- 组合属于有效组合集。
- 每层空间有效（逐层）：
  对任意 `i in [1, N]`，满足
  `S_eff_i.length >= S_req_i.length`，
  `S_eff_i.width >= S_req_i.width`，
  `S_eff_i.height >= S_req_i.height`。
- 每层承重有效（逐层）：
  对任意 `i in [1, N]`，满足
  `P_req_i <= P_allow_i / gamma`。
- 效率定义（统一口径）：
  `target_efficiency = A_panel_sum_target / A_footprint_proj_target`，
  `baseline_efficiency = A_panel_sum_baseline / A_footprint_proj_baseline`。
- 效率比较有效：
  `A_footprint_proj_target > 0` 且 `A_footprint_proj_baseline > 0`，
  并满足 `target_efficiency > baseline_efficiency`。
